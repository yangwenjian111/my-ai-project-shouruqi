# 日常记账 · UI 原型

基于 Ardot 设计稿一比一转换的纯静态 UI 原型，共 9 个页面（375×812 移动端画板）。
无构建工具、无 npm 依赖、无框架 —— **双击 `index.html` 即可在浏览器打开**。

## 页面跳转关系

```
登录/注册 ──登录成功──→ 首页 ──FAB按钮──→ 快速记账面板
                         │                    │
                         │ 点击账单条目         │ 完成
                         ▼                    ▼
                    账单详情 Sheet ←──── 首页
                         │
                    编辑/删除
                         │
                         ▼
  ┌────────┐  ┌────────┐  ┌────────┐
  │ 账单页  │  │ 统计页  │  │ 预算页  │  ← 底部 Tab 导航
  └────────┘  └────────┘  └────────┘  ┌────────┐
                                       │ 设置页  │
                                       └────────┘
```

- **底部 Tab 导航**：首页 | 账单 | 统计 | 预算 | 设置（5 个主页面互通）
- **登录/注册**：独立全屏页面，不在 Tab 导航内
- **弹窗页面**：快速记账面板、账单详情为底部 Sheet 弹出

## 自带交互（js/app.js，原生 JS）

- 画板按窗口**等比缩放**居中显示
- 底部导航 / 悬浮记账按钮 / 账单条目 / 登录注册入口 / 返回按钮 **页面跳转**
- 分段控件点击切换：支出-收入、全部-支出-收入、周-月-年、浅色-深色-跟随系统
- 快速记账面板的**数字键盘**可以真的录入金额
- 输入框点击有聚焦高亮

## 代码怎么读

- **每个元素都带 `id="2:122"` 和 `data-name="本月概览卡片"`**，和 Ardot 画板里的图层一一对应，
  想改哪个块，直接在 HTML 里搜中文名就能定位。
- `style.css` 里的 `.layer640` 这类类名是导出器生成的，一个类对应一个图层的尺寸/位移，
  语义不强但值是准确的；**覆盖样式请写在 `app.css`**。
- 图标不是图片，是 `<svg><use href="#p7"/></svg>`，路径都收在 `js/icons.js` 的雪碧图里。

## 常见改法

```css
/* app.css 里加一句就能全局换主色（粉色） */
.stage [data-name="登录按钮"],
.stage [data-name="完成按钮"] { filter: hue-rotate(30deg); }
```

```js
// app.js 里的 NAV 表控制所有跳转，想加页面就加一行
var NAV = { '首页Tab': 'home.html', /* ... */ };
```

## 一、产品概述

### 1.1 产品定位

一款面向个人的轻量级日常财务记录工具，帮助用户快速记录每日消费、查看支出分布、掌握财务状况，培养良好的记账习惯。

### 1.2 目标用户

- 有日常记账需求的个人用户
- 希望了解自己消费结构、控制开支的人群
- 不依赖复杂财务功能，追求简洁高效的轻量使用者

### 1.3 核心价值

| 价值点 | 说明 |
|--------|------|
| **快速记录** | 3 秒内完成一笔消费记录 |
| **清晰可视** | 图表化展示消费分布，一目了然 |
| **分类管理** | 预设 + 自定义分类，贴合个人消费场景 |
| **本地优先** | V1.0 数据存本地（LocalStorage），轻量注册即用 |

### 1.4 视觉风格

整体采用 **粉嫩温馨** 的视觉基调，营造柔和、舒适、愉悦的使用氛围，让用户在记账时感到轻松而非压力。

## 三、功能模块详细设计

### 3.0 登录/注册页（Auth）

> V1.0 采用 **前端本地注册** 方案：用户信息存储在 LocalStorage 中，无后端服务依赖。旨在提供基本的身份区分能力，为后续云端同步做铺垫。

#### 3.0.1 登录页

**页面布局**（全屏居中卡片）：

| 元素 | 说明 |
|------|------|
| Logo + 应用名 | 顶部居中，樱花粉品牌色 |
| 欢迎语 | 「欢迎回来，开始今天的记账吧」 |
| 用户名输入框 | 文本输入，支持 3-20 位字符 |
| 密码输入框 | 密码输入，右侧显示/隐藏切换图标 |
- 登录按钮：主色渐变按钮（粉→橙），全宽
- 注册头像回显：已注册用户登录时显示注册时选择的头像（SVG 笑脸风格）
- 注册入口 | 底部链接「还没有账号？立即注册」
- 忘记密码入口 | 登录按钮下方链接「忘记密码？」（V1.0 仅展示入口，功能后续实现）

**交互说明**：
- 输入框获焦时，边框变为樱花粉色 + 柔和发光
- 点击登录 → 校验用户名和密码非空 → 成功跳转首页，失败显示「请输入用户名和密码」
- V1.0 登录为简化流程：不校验注册数据，直接跳转 dashboard.html
- 页面背景使用浅粉渐变 `#FDDDE6 → #FFF8F0`

#### 3.0.2 注册页

**页面布局**（全屏居中卡片，与登录页风格一致）：

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| 用户名 | 文本输入 | 是 | 3-20 位，支持中英文、数字、下划线 |
| 昵称 | 文本输入 | 否 | 最多 15 字，默认「记账达人」 |
| 密码 | 密码输入 | 是 | 6-20 位，至少含字母和数字 |
| 确认密码 | 密码输入 | 是 | 必须与密码一致 |
| 头像 | 图标选择 | 否 | 5 种预设 SVG 笑脸头像（粉/橙/薄荷/淡紫/蓝），默认粉色 |

**交互说明**：
- 密码强度指示器：弱（红色）→ 中（暖橙）→ 强（薄荷绿），实时反馈（基于长度、大小写、数字、特殊字符）
- 确认密码不匹配时，Toast 提示「两次密码不一致」
- 用户名少于 3 位时 Toast 提示「用户名至少3位」
- 密码少于 6 位时 Toast 提示「密码至少6位」
- 点击「注册」→ 创建用户数据（username + userAvatar）存入 LocalStorage → Toast「注册成功！」→ 1 秒后跳转 login.html
- 底部链接「已有账号？去登录」切换回登录页

#### 3.0.3 忘记密码（本地找回）

**V1.0 状态**：仅展示入口链接，功能未实现。后续版本规划。

#### 3.0.4 登录态管理

| 场景 | 行为 |
|------|------|
| 首次打开应用 | 直接访问 login.html（无路由守卫） |
| 登录成功 | 跳转 dashboard.html |
| 退出登录 | 二次确认「确定退出登录？」→ Toast「已退出登录」→ 跳转 login.html |
| 头像回显 | 登录页和设置页读取 localStorage 中的 userAvatar，显示对应颜色 SVG 笑脸头像 |

### 3.1 首页（Dashboard）

#### 3.1.1 本月概览卡片

| 字段 | 说明 |
|------|------|
| 本月收入 | 当月所有收入类账单总和 |
| 本月支出 | 当月所有支出类账单总和 |
| 本月结余 | 收入 - 支出，正数绿色，负数红色 |
| 预算进度条 | 已支出 / 月预算，百分比展示，超支变红 |

**交互说明**：
- 点击卡片 → 跳转至账单页，自动筛选当月数据
- 左右滑动卡片 → 切换上/下月数据

#### 3.1.2 近期账单流水

- 按日分组展示最近 7 天的账单
- 每条记录显示：**分类图标 + 备注 + 金额**
- 每日小计显示在日期标题右侧
- 无数据时显示空状态插画 + "开始记第一笔"引导按钮

**交互说明**：
- 左滑单条 → 露出「编辑」「删除」按钮
- 点击单条 → 进入账单详情弹窗（底部弹出 Sheet）
- 列表底部 → "查看全部"链接，跳转账单页

#### 3.1.3 快速记账（FAB 按钮）

- 页面右下角常驻浮动按钮（+号图标）
- 点击 → 弹出快速记账面板（半屏 Sheet）

**快速记账面板字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 类型 | Tab 切换 | 是 | 支出 / 收入，默认"支出" |
| 金额 | 数字键盘 | 是 | 调起自定义数字键盘，精确到小数点后两位 |
| 分类 | 图标网格 | 是 | 展示常用分类图标，可横向滚动查看更多 |
| 日期 | 日期选择器 | 否 | 默认今天，可修改 |
| 备注 | 文本输入 | 否 | 最多 50 字 |

**交互说明**：
- 点击"完成"→ 保存数据到 localStorage → Toast「记账成功！」→ 重置金额和备注 → **面板关闭**
- 点击面板外遮罩区域 → 面板收起
- 备注输入框聚焦时，自定义小键盘禁用（变灰），调用系统键盘输入备注
- 备注输入框失焦后，小键盘重新启用
- 支持物理键盘输入（备注聚焦时不拦截）

## 四、全局交互规范

### 4.1 导航结构

- 底部 Tab 导航：首页 | 账单 | 统计 | 预算 | 设置
- 共 5 个一级页面，Tab 间切换无动画（或轻微淡入淡出）
- 弹窗类操作用底部 Sheet（半屏弹出）
- 登录/注册页为独立全屏页面，不在底部 Tab 导航内

### 4.2 数字键盘

- 自定义数字键盘，仅包含数字 0-9、小数点、退格（× 图标）
- 金额格式：直接拼接数字字符串，显示在金额区域
- 键盘顶部显示当前输入金额（大号字体）
- **备注输入联动**：备注输入框聚焦时小键盘禁用（opacity: 0.35），调用系统键盘；失焦后小键盘恢复
- **物理键盘支持**：面板打开时支持物理键盘输入数字，备注聚焦时不拦截

### 4.3 空状态

所有列表类页面在无数据时展示：
- 插画图标（与页面主题相关）
- 引导文案（如"还没有账单记录，去记一笔吧"）
- 操作按钮（如"立即记账"）

### 4.4 加载状态

- 操作反馈：按钮点击后显示 loading 状态（V1.0 简化处理）
- 保存成功：轻量 Toast 提示（1.5s 自动消失），错误红色 `#E8849E`，成功绿色 `#7BC89C`，警告橙色 `#FFB347`

### 4.5 删除确认

- 所有删除操作需二次确认弹窗
- 弹窗内容：明确告知删除后果（如"删除后无法恢复，确定删除？"）
- 按钮：取消（主按钮）| 确认删除（危险色按钮）

## 七、数据存储方案（V1.0 前端本地）

### 7.1 存储方式

- 使用 `localStorage` 存储所有数据
- 数据结构采用 JSON 格式
- 每次操作后即时保存

### 7.2 数据模型（前端定义）

```typescript
// 账单记录（V1.0 实际存储结构）
interface Transaction {
  id: string;              // 唯一ID（时间戳 + 随机数）
  type: 'expense' | 'income';  // 类型
  amount: number;          // 金额（单位：元）
  category: string;        // 分类名称（如"餐饮"、"交通"）
  date: string;            // 日期（如"9月22日"）
  note: string;            // 备注（可选）
  createdAt: string;       // 创建时间（ISO 8601）
}

// 分类（V1.0 为硬编码，未独立存储）
// 支出分类：餐饮、交通、购物、娱乐
// 收入分类：兼职

// 用户信息（V1.0 实际存储字段）
interface User {
  username: string;        // 用户名（localStorage key: 'username'）
  userAvatar: string;      // 头像颜色标识（localStorage key: 'userAvatar'）
                           // 可选值：'pink' | 'orange' | 'mint' | 'lavender' | 'blue'
}

// 头像颜色映射
interface AvatarColors {
  pink:     { bg: '#FDDDE6', fill: '#E8849E' };
  orange:   { bg: '#FFE5C2', fill: '#FFD6A5' };
  mint:     { bg: '#D5F5E8', fill: '#B8E6D0' };
  lavender: { bg: '#E8DFF5', fill: '#C9B8E6' };
  blue:     { bg: '#D5EEF5', fill: '#A8D8EA' };
}
```

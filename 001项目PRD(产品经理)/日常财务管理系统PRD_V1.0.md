## 一、产品概述

### 1.1 产品定位

一款面向个人的轻量级日常财务记录工具，帮助用户快速记录每日消费、查看支出分布、掌握财务状况，培养良好的记账习惯。

### 1.2 目标用户

- 有日常记账需求的个人用户
- 希望了解自己消费结构、控制开支的人群
- 不依赖复杂财务功能，追求简洁高效的轻量使用者

### 1.3 核心价值

| 价值点 | 说明 |
|--------|------|
| **快速记录** | 3 秒内完成一笔消费记录 |
| **清晰可视** | 图表化展示消费分布，一目了然 |
| **分类管理** | 预设 + 自定义分类，贴合个人消费场景 |
| **本地优先** | V1.0 数据存本地（LocalStorage），轻量注册即用 |

### 1.4 视觉风格

整体采用 **粉嫩温馨** 的视觉基调，营造柔和、舒适、愉悦的使用氛围，让用户在记账时感到轻松而非压力。

## 三、功能模块详细设计

### 3.0 登录/注册页（Auth）

> V1.0 采用 **前端本地注册** 方案：用户信息存储在 LocalStorage 中，无后端服务依赖。旨在提供基本的身份区分能力，为后续云端同步做铺垫。

#### 3.0.1 登录页

**页面布局**（全屏居中卡片）：

| 元素 | 说明 |
|------|------|
| Logo + 应用名 | 顶部居中，樱花粉品牌色 |
| 欢迎语 | 「欢迎回来，开始今天的记账吧」 |
| 用户名输入框 | 文本输入，支持 3-20 位字符 |
| 密码输入框 | 密码输入，右侧显示/隐藏切换图标 |
| 登录按钮 | 主色渐变按钮（粉→橙），全宽 |
| 注册入口 | 底部链接「还没有账号？立即注册」 |
| 忘记密码入口 | 登录按钮下方链接「忘记密码？」 |

**交互说明**：
- 输入框获焦时，边框变为樱花粉色 + 柔和发光
- 登录按钮在未填写完整时为禁用态（灰色）
- 点击登录 → 校验本地用户数据 → 成功跳转首页，失败显示「用户名或密码错误」
- 登录成功后将用户信息写入 `sessionStorage`，保持会话状态
- 页面背景使用浅粉渐变 `#FDDDE6 → #FFF8F0`

#### 3.0.2 注册页

**页面布局**（全屏居中卡片，与登录页风格一致）：

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| 用户名 | 文本输入 | 是 | 3-20 位，支持中英文、数字、下划线 |
| 昵称 | 文本输入 | 否 | 最多 15 字，默认「记账达人」 |
| 密码 | 密码输入 | 是 | 6-20 位，至少含字母和数字 |
| 确认密码 | 密码输入 | 是 | 必须与密码一致 |
| 头像 | 图标选择 | 否 | 从预设可爱头像库中选择，默认粉色小猫 |

**交互说明**：
- 密码强度指示器：弱（红色）→ 中（暖橙）→ 强（薄荷绿），实时反馈
- 确认密码不匹配时，输入框下方显示红色提示「两次密码不一致」
- 用户名已存在时，失焦后显示提示「该用户名已被使用」
- 点击「注册」→ 创建用户数据存入 LocalStorage → 自动登录跳转首页
- 注册成功显示 Toast「注册成功，欢迎加入！」
- 底部链接「已有账号？去登录」切换回登录页

#### 3.0.3 忘记密码（本地找回）

**流程**：
1. 点击「忘记密码」→ 进入找回页面
2. 输入注册时的用户名
3. 回答预设的安全问题（注册时设置）
4. 验证通过 → 允许重设密码
5. 设置新密码后 → 跳转登录页

**安全问题设置**（注册时可选）：
- 预设问题列表（如「你的宠物叫什么？」「你的小学名字？」）
- 用户选择一题并填写答案
- 未设置安全问题时，忘记密码功能不可用，提示「请联系管理员或重新注册」

#### 3.0.4 登录态管理

| 场景 | 行为 |
|------|------|
| 首次打开应用 | 无已登录用户 → 跳转登录页 |
| 登录成功 | 写入 sessionStorage，跳转首页 |
| 刷新页面 | 从 sessionStorage 恢复登录态，无需重新登录 |
| 关闭浏览器再打开 | sessionStorage 清空 → 需重新登录 |
| 勾选「记住我」 | 写入 localStorage，7 天内免登录 |
| 退出登录 | 清除 session/localStorage 中的登录态 → 跳转登录页 |
| 未登录访问内部页面 | 路由守卫拦截 → 重定向到登录页 |

### 3.1 首页（Dashboard）

#### 3.1.1 本月概览卡片

| 字段 | 说明 |
|------|------|
| 本月收入 | 当月所有收入类账单总和 |
| 本月支出 | 当月所有支出类账单总和 |
| 本月结余 | 收入 - 支出，正数绿色，负数红色 |
| 预算进度条 | 已支出 / 月预算，百分比展示，超支变红 |

**交互说明**：
- 点击卡片 → 跳转至账单页，自动筛选当月数据
- 左右滑动卡片 → 切换上/下月数据

#### 3.1.2 近期账单流水

- 按日分组展示最近 7 天的账单
- 每条记录显示：**分类图标 + 备注 + 金额**
- 每日小计显示在日期标题右侧
- 无数据时显示空状态插画 + "开始记第一笔"引导按钮

**交互说明**：
- 左滑单条 → 露出「编辑」「删除」按钮
- 点击单条 → 进入账单详情弹窗（底部弹出 Sheet）
- 列表底部 → "查看全部"链接，跳转账单页

#### 3.1.3 快速记账（FAB 按钮）

- 页面右下角常驻浮动按钮（+号图标）
- 点击 → 弹出快速记账面板（半屏 Sheet）

**快速记账面板字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 类型 | Tab 切换 | 是 | 支出 / 收入，默认"支出" |
| 金额 | 数字键盘 | 是 | 调起自定义数字键盘，精确到小数点后两位 |
| 分类 | 图标网格 | 是 | 展示常用分类图标，可横向滚动查看更多 |
| 日期 | 日期选择器 | 否 | 默认今天，可修改 |
| 备注 | 文本输入 | 否 | 最多 50 字 |

**交互说明**：
- 金额输入完成后自动聚焦到分类选择
- 点击"完成"→ 保存并显示轻量成功提示（Toast），面板不关闭，金额清空，方便连续记账
- 点击面板外区域 → 面板收起（如有未填必填项，弹出确认"放弃编辑？"）

#### 3.2.1 月度账单列表

- 顶部月份选择器：`< 2026年9月 >`，左右箭头切换月份

| 筛选项 | 说明 |
|--------|------|

**交互说明**：
- 顶部搜索栏默认收起，点击搜索图标展开
- 筛选条件以标签形式展示，点击弹出底部筛选面板

#### 3.2.3 账单详情（底部 Sheet 弹窗）

| 字段 | 展示 |

| 类型 | 支出/收入 标签 |

### 3.4 预算页（Budget）

#### 3.4.1 月度总预算

- 顶部大卡片显示：月预算总额 + 已使用金额 + 剩余金额
- 环形进度图展示使用百分比
- 未设置预算时显示引导："设置月度预算"

- 列表展示各分类的预算设置

**交互说明**：
- 点击某分类 → 弹出金额编辑弹窗

#### 3.4.3 预算预警

- 当某分类使用超过 90% 时，首页显示黄色提醒条
- 当某分类超支时，首页显示红色警告条
- 点击提醒条 → 跳转至预算页对应分类

## 四、全局交互规范

### 4.1 导航结构

- 底部 Tab 导航：首页 | 账单 | 统计 | 预算 | 设置
- 共 5 个一级页面，Tab 间切换无动画（或轻微淡入淡出）
- 弹窗类操作用底部 Sheet（半屏弹出）
- 登录/注册页为独立全屏页面，不在底部 Tab 导航内

### 4.2 数字键盘

- 自定义数字键盘，仅包含数字 0-9、小数点、退格
- 金额格式：千分位分隔，最多两位小数
- 键盘顶部显示当前输入金额（大号字体）

### 4.3 空状态

所有列表类页面在无数据时展示：
- 插画图标（与页面主题相关）
- 引导文案（如"还没有账单记录，去记一笔吧"）
- 操作按钮（如"立即记账"）

### 4.4 加载状态

- 首次加载：骨架屏（Skeleton）占位
- 操作反馈：按钮点击后显示 loading 状态
- 保存成功：轻量 Toast 提示（1.5s 自动消失）

### 4.5 删除确认

- 所有删除操作需二次确认弹窗
- 弹窗内容：明确告知删除后果（如"删除后无法恢复，确定删除？"）
- 按钮：取消（主按钮）| 确认删除（危险色按钮）

### 4.6 手势交互

| 手势 | 场景 | 行为 |
|------|------|------|
| 左滑 | 账单列表项 | 露出编辑/删除操作 |
| 下拉 | 首页 | 刷新数据 |
| 左右滑动 | 月份/周/年切换 | 切换时间区间 |

## 七、数据存储方案（V1.0 前端本地）

### 7.1 存储方式

- 使用 `localStorage` 存储所有数据
- 数据结构采用 JSON 格式
- 每次操作后即时保存

### 7.2 数据模型（前端定义）

```typescript
// 账单记录
interface Transaction {
  id: string;              // 唯一ID（时间戳 + 随机数）
  type: 'expense' | 'income';  // 类型
  amount: number;          // 金额（单位：元，精确到分）
  categoryId: string;      // 分类ID
  date: string;            // 日期（ISO 8601 格式）
  note: string;            // 备注（可选）
  createdAt: string;       // 创建时间
  updatedAt: string;       // 更新时间
}

// 分类
interface Category {
  id: string;              // 唯一ID
  name: string;            // 分类名称
  icon: string;            // 图标标识
  type: 'expense' | 'income';  // 分类类型
  sortOrder: number;       // 排序权重
  isDefault: boolean;      // 是否预设分类
}

// 预算
interface Budget {
  id: string;              // 唯一ID
  categoryId: string;      // 分类ID（空字符串表示总预算）
  amount: number;          // 预算金额
  month: string;           // 月份（YYYY-MM 格式）
}

// 用户信息
interface User {
  id: string;              // 唯一ID（时间戳 + 随机数）
  username: string;        // 用户名（唯一）
  nickname: string;        // 昵称
  password: string;        // 密码（简单哈希存储）
  avatar: string;          // 头像标识
  securityQuestion?: string;  // 安全问题
  securityAnswer?: string;    // 安全问题答案
  rememberMe?: boolean;    // 是否记住登录
  createdAt: string;       // 注册时间
  updatedAt: string;       // 更新时间
}

// 用户设置
interface UserSettings {
  defaultType: 'expense' | 'income';
  currency: string;        // 货币符号
  monthStartDay: number;   // 每月起始日
  theme: 'light' | 'dark' | 'system';
}
```

# 记账簿 · 静态页

由 Ardot 设计稿《记账簿》（9 个画板，375×812 移动端）一比一转换而来的纯静态页面。
无构建工具、无 npm 依赖、无框架 —— **双击任意 HTML 即可在浏览器打开**。

## 页面清单

| 文件 | 页面 | 说明 |
| --- | --- | --- |
| `index.html` | 总览 | 9 个页面的缩略图导航（推荐先打开这个） |
| `login.html` | 登录页 | 用户名/密码输入、登录按钮、注册入口 |
| `register.html` | 注册页 | 注册表单、密码强度条、头像选择 |
| `home.html` | 首页 | 问候语、本月概览卡片、近期账单、悬浮记账按钮、底部导航 |
| `quick-entry.html` | 快速记账面板 | 支出/收入切换、分类网格、数字键盘 |
| `bills.html` | 账单页 | 月份切换、筛选、按日期分组的账单流水 |
| `bill-detail.html` | 账单详情 | 金额卡片、日期备注、编辑/删除 |
| `stats.html` | 统计页 | 周/月/年切换、趋势折线图、分类占比环形图、消费排行 |
| `budget.html` | 预算页 | 总预算环形进度、分类预算进度条 |
| `settings.html` | 设置页 | 个人信息、偏好、主题切换、关于 |

## 目录结构

```
记账簿静态页/
├── index.html          总览页（缩略图 + 链接）
├── *.html              9 个页面，每页一个文件
├── css/
│   ├── style.css       设计稿图层样式（Ardot 导出，改样式请别动这个文件）
│   └── app.css         手写补充样式：字体、预览舞台、交互态
└── js/
    ├── icons.js        SVG 图标雪碧图（运行时注入，页面里 <use href="#p7"> 引用）
    └── app.js          轻交互：缩放、页面跳转、分段控件、数字键盘
```

## 代码怎么读

- **每个元素都带 `id="2:122"` 和 `data-name="本月概览卡片"`**，和 Ardot 画板里的图层一一对应，
  想改哪个块，直接在 HTML 里搜中文名就能定位。
- `style.css` 里的 `.layer640` 这类类名是导出器生成的，一个类对应一个图层的尺寸/位移，
  语义不强但值是准确的；**覆盖样式请写在 `app.css`**。
- 图标不是图片，是 `<svg><use href="#p7"/></svg>`，路径都收在 `js/icons.js` 的雪碧图里。

## 自带的交互（js/app.js，原生 JS）

- 画板按窗口**等比缩放**居中显示
- 底部导航 / 悬浮记账按钮 / 账单条目 / 登录注册入口 / 返回按钮 **页面跳转**
- 分段控件点击切换：支出-收入、全部-支出-收入、周-月-年、浅色-深色-跟随系统
  （切换时互换两段的背景与文字颜色，和设计稿的选中态保持一致）
- 快速记账面板的**数字键盘**可以真的录入金额
- 输入框点击有聚焦高亮

## 改字体

设计稿字体是 **Noto Sans SC**（思源黑体）。`app.css` 里 `.tx` 的 font-family 依次回退：
`Noto Sans SC → 苹方 → 微软雅黑`。装上 Noto Sans SC 后观感和设计稿完全一致。

## 常见改法

```css
/* app.css 里加一句就能全局换主色（粉色） */
.stage [data-name="登录按钮"],
.stage [data-name="完成按钮"] { filter: hue-rotate(30deg); }
```

```js
// app.js 里的 NAV 表控制所有跳转，想加页面就加一行
var NAV = { '首页Tab': 'home.html', /* ... */ };
```
